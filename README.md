# 倉敷市の浸水リスク可視化マップ

国土交通省のハザードマップデータを使って、倉敷市の一部地域を対象に、想定浸水深を色分けした地図を作成しました。

## 概要

- 対象エリア: 倉敷駅周辺
- 使うデータ: 国土交通省の浸水想定区域データ
- 生成方法: GeoPandas + Folium
- 出力形式: HTML 地図

## 必要なもの

- Python 3.10 以上
- 国土交通省の Shapefile データ
- 以下のライブラリ

```bash
pip install -r requirements.txt
```

## ファイル構成

- `code`: 地図生成スクリプト
- `requirements.txt`: 必要な Python パッケージ
- `A31-21_33_GML/A31a-21_33.shp`: 浸水想定区域データ（事前に配置が必要）

## 実行手順

1. 下記のデータを準備し、リポジトリ直下に `A31-21_33_GML` フォルダを作成してください。
   - `A31a-21_33.shp`
   - 必要に応じて関連ファイル（.shx, .dbf, .prj など）
2. 依存ライブラリをインストールします。

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

3. スクリプトを実行します。

```bash
python code
```

4. 実行後、`kurashiki_flood_map_perfect.html` が生成されます。
5. ブラウザで開いて内容を確認してください。

## 注意事項

- 国土交通省の Shapefile は文字コードが `cp932` の場合があるため、スクリプト側で `encoding="cp932"` を指定しています。
- 画面が重くなるため、対象範囲は `bbox` により倉敷駅周辺にクリッピングしています。
- データが見つからない場合は、`file_path` を自分の環境に合わせて修正してください。

## 参考

このプロジェクトは、倉敷市の特定エリアにおける想定浸水リスクを地図として視覚化するための試作です。
